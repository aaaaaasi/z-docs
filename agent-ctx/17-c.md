## Algorithm details (tracker)

- **Baseline load (constructor-time async GET)**: `GET /api/documents/:id/stats` with `credentials: "same-origin"`; events observed before it resolves accumulate into a local `delta`; the merge is computed lazily on every `snapshot()`/`flush()` so nothing is lost ("加载后合并"). Defensive `parseServerStats` whitelists the 10 fields, coerces garbage to 0/"".
- **State model**: `base` (server totals) + `LocalDelta` (never-persisted increments: activeMs/pauses/pauseMs/keystrokes/typedChars/typedWords/pastedChars/extraSessions/openedSession/startedAt/lastAt). Pure closure state, zero React.
- **`observe(el)`**: attaches `beforeinput` (pure observation, never preventDefault) + `compositionend`; returns a detach that removes both.
  - `insertText`: `keystrokes++`, `typedChars += data.length`; word: `typedWords++` if data contains whitespace.
  - `insertCompositionText` (IME): compositions REWRITE the whole pending string on every update, so only the **growth** (`data.length − compositionLen`) is credited as typed chars — typing 你好 via IME counts 2, not ~5. `compositionend` records the committed text; an `insertText` re-firing that exact text within 250 ms (engine commit echo) is deduped; genuine later typing of the same char still counts.
  - `insertFromPaste` / `insertFromPasteAsQuotation`: `pastedChars += dataTransfer.getData("text/plain").length` — **never a keystroke** (per spec).
  - `delete*` (any inputType starting with "delete"): `keystrokes++` ("敲击即活动").
  - `insertParagraph` / `insertLineBreak`: `keystrokes++`, `typedWords++`.
  - Unrecognized inputTypes (formatting/history/drop) are ignored entirely.
- **Time accounting (per recognized event, `now = Date.now()`)**:
  - gap ≤ 5 s → `activeMs += gap` (有效写作);
  - 5 s < gap ≤ 30 min → `pauses++`, `pauseMs += gap` (思考停顿);
  - gap > 30 min → `extraSessions++` (新写作环节, no pause/active credit);
  - first event ever → `openedSession = true`, `startedAt = now`; merged sessions = `base.sessions + extraSessions + (base.sessions === 0 && openedSession ? 1 : 0)` — exactly the spec's `sessions = max(1, 已存 sessions)`;
  - negative gaps (clock jumps) are skipped; `lastAt` = latest event.
- **`flush()`** (dirty-only, in-flight-deduped): awaits the baseline load, **refuses to PATCH while the GET hasn't succeeded** (a local-only PATCH would clobber bigger server totals — on GET failure it resets `loadPromise` so the next 30 s flush retries the baseline), then PATCHes the full merged object (`credentials: "same-origin"`, `keepalive: true` for unload flushes). Success clears `dirty` only when no event arrived during the round-trip (`eventSeq` generation check). 401/403/network errors are swallowed silently; in-memory values and the dirty flag are kept for a later retry.
- **`snapshot()`**: fresh merged object every call; `null` when no local events AND no server data.

## UI details (writing-metrics.tsx)

- On `open` → one extra `GET /api/documents/:id/stats` (cancelled-safe effect); server values (when non-empty) win over the live tracker snapshot prop; `editCount` likewise. Live 总字数 always recomputed from `html` via `htmlToText`+`countWords` (`@/lib/doc-utils`).
- **8 cards** (`grid grid-cols-2 sm:grid-cols-4 gap-3`, `rounded-xl border bg-card p-4`, lucide icon + `t()` title + `tnum` value):
  1. 总字数 `≈{n} 字` (FileText) 2. 有效写作时间 `formatDuration(activeMs)` (Timer, tooltip: 仅统计实际击键时间) 3. 写作次数 sessions (Repeat, tooltip: >30min 新环节) 4. 平均写作速度 (Gauge): zh 主`{n} 字/分钟` + 副`{n} 词/分钟`, en 主 words/min + 副 chars/min, `—` when activeMs=0; paste excluded 5. 思考停顿 (Pause): 次数 + `共 X 分 Y 秒` 副行, tooltip >5s 6. 总编辑次数 editCount (History, 服务端计数) 7. 字数与修改次数比率 (Ratio): words/editCount 保留 1 位小数, `—` when editCount=0 8. 粘贴比例 (ChartPie): `%` + `role=progressbar` 迷你进度条 (primary on muted).
- Numbers use `Intl.NumberFormat(localeOf(lang))` (0/1 fraction digits per metric); durations `X 小时 Y 分 Z 秒` / `Y 分 Z 秒` / `Z 秒` (compact en `1h 2m 3s`).
- Tooltips on every card header (Radix `Tooltip`, keyboard-focusable, Info hint icon); empty state (stats all-zero/null AND editCount=0): PenLine badge + "开始写作后，这里会展示你的写作历程。".
- Layout contract: own scroll container `max-h-[min(28rem,55dvh)] overflow-y-auto slim-scroll pr-1` inside the already-capped `DialogContent`; cards wrap values (`break-words`) instead of overflowing at 375 px; long title "字数与修改次数比率" truncates within the 11 px header row.
