### REST 守卫规则（sheets/slides/forms 三应用一致）
- **GET 列表**：`guardRoute` → 401 短路；非 admin 追加 `OR: [{ownerId: user.id}, {ownerId: null}]`（legacy ownerless 可见），admin 全量。filter/starred/q/排序逻辑原样保留。
- **POST 创建**：`guardRoute({mutating:true})`（同源校验 + 限流）→ `ownerId: user.id` 落库。
- **GET [id]**：`guardRoute` + `ownedAccessLevel` → `none` → **404**（隐藏存在性）。
- **PATCH/DELETE [id]**：`none` 时先查存在性：不存在 → 404，存在但属他人 → **403**（明确拒绝，id 为不可枚举 cuid）；`viewer`（legacy）→ 403；owner/admin 放行（`hasAccess(level,"owner")`）。
- **forms/[id]/responses GET**：owner/admin only（回复数据是机主资产）：none → 404，viewer → 403。
- **forms/[id]/responses POST**（匿名提交，类 Google Forms）：**不用 guardRoute**（会 401 受访者），手工组合：
  - `rateLimit(\`formresp:${clientIp(req)}\`, 8, 10min)` → 429
  - body 校验：answers 必须是纯对象、值为 string/number/其数组、序列化 ≤20KB → 400/413
  - 表单存在且未 trashed → 否则 404/410
  - 响应只回 `{id, submittedAt}` ack —— **不回显表单数据**（原先会回显 answers/formId）
  - 活动日志 actor：`getSessionUser`（登录受访者归因真实账号，匿名 → "Anonymous respondent"）
- **活动日志 actor 全面改源**：这些路由里所有 `actorFromRequest(req)`（信任客户端 x-z-actor 头）→ `actorFromUser(session user)`（守卫已给的会话用户），杜绝伪造归因。

### AI 路由（write/transform）
两个 POST 顶部加 `guardRoute(req, {mutating: true, limit: 6, windowMs: 60_000})` → 401（未登录）/403（跨源）/429（每用户每分钟 6 次）在 **任何 ZAI 调用之前**短路；lang==="zh" 提示词逻辑、输入长度校验、错误处理完全未动。

### collab-service 实时鉴权（核心）
- `join-doc` 改 **async**：payload 严格校验（docId 字符串 ≤40 字符，否则忽略）→ 从 `socket.request.headers.cookie` 取浏览器原始 cookie → `fetch http://localhost:3000/api/internal/doc-access?docId=…`（headers: 原样 cookie + `x-internal-secret: INTERNAL_SECRET`，bun 自动加载 collab-service/.env，3s AbortController 超时）→ 解析 `{access, user}`：
  - `access === "none"`（含 app :3000 挂掉/超时/非 200/坏 payload —— **fail closed**）→ `socket.emit("join-error", {message:"No access"})`，**不进 room、不发 presence**
  - viewer → 可 join + 收 presence/doc-change（看到实时内容），但该 socket 的 doc-change 在 handler 里被**服务端权威丢弃**（`sessions.get(socket.id).access === "viewer"` → return 不广播）
  - editor/owner/admin → 完整读写中继
- 会话状态 `{docId, user, access}`；presence 身份用 **API 返回的服务端验证身份**（防客户端伪造姓名/颜色），仅 API 无身份时回退 client payload
- **房间注入防御**：doc-change/cursor/comments-changed 三个 handler 都要求 `session.docId === payload.docId`（socket 未 join 该 room 的中继一律丢弃）；doc-change 另加 content 必须为 string 且 ≤1MB
- leave-doc / disconnect 清理逻辑保留（access 一并重置）
- 前端 `use-collab.ts`（特批）：新增 `socket.on("join-error", …)` → console.warn + setConnected(false) + socket.disconnect()
- package.json **零新依赖**（用 bun 内置 fetch）

### next.config.ts 安全响应头（保留原有 standalone/ignoreBuildErrors/reactStrictMode）
`X-Content-Type-Options: nosniff` / `Referrer-Policy: strict-origin-when-cross-origin` / `Permissions-Policy: camera=(), microphone=(self), geolocation=()` / `X-XSS-Protection: 0` / `Content-Security-Policy: object-src 'none'`。**刻意不加** X-Frame-Options/frame-ancestors（沙箱预览 iframe 会挂）和严格 CSP（Turbopack dev 内联脚本会挂）。
