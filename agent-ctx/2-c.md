### Key decisions / contract handling
- **POST /api/forms echoes `data:"[]"`** — creation + duplication never trust the returned `data`; the locally-built FormState carries the questions we sent.
- Autosave: snapshot-ref (JSON of title/description/data) + 900 ms debounce; flush on leaving builder, on unmount, and re-schedules if edits arrive mid-flight; error toast is deduped until next success. Star toggles bypass autosave (payload excludes `starred`).
- `consumeAppTarget()` called once on mount with ref guard → `formMode` "edit"/"fill"/"responses" respected; no target → list (self-fetching via `useFormsList`).
- Escaping builder for fill/responses flushes the save; fill preview reads local state so it's always current.
- Duplicate = client-side `POST /api/forms` with `{title: "Copy of X", description, data}` per spec.
- All fetches through `api` (x-z-actor stamped). Toasts via `useToast` (root `<Toaster/>` already mounted in layout). Tooltips via own nested-safe `TooltipProvider`.
