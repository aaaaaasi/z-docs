### Engine — mixed zh/en tokenization
- **Sentences**: terminate at 。！？!? … . and newline; terminator runs (`?!`, `...`, `……`) count as ONE break; glued closers (`”` `」` `』` `）` …) are absorbed into the finished sentence so quotes stay intact for in-document locating. `.` guards: decimals (`3.14`), abbreviation list (Dr./Ms./etc./e.g./i.e./U.S…). Sentences kept verbatim (trimmed), dropped if they contain no letter/CJK.
- **Words**: maximal Latin runs (incl. `can't`/`well-known`) = 1 word; every CJK char = 1 word (`[\u4e00-\u9fff]`). Global mixed regex — per-paragraph processing implicit.
- Stopword sets exactly per spec (EN 32 words + ZH 46 chars).

### The 15 metrics (implementation notes)
1. **textComplexity** — latin-token ratio > 50% → Flesch–Kincaid grade (0.39·wps + 11.8·spw − 15.59; syllables via vowel-group heuristic with silent-e/-le handling; clamp 1–20). CJK → `avgSentenceLen·1.0 + rareRate·15` (clamped 1–16); rareRate = CJK chars outside an embedded ~1,180-char common-character set (calibrated: everyday zh text ≈ 1–2% rare, 耄耋-type chars count rare). Returns `{grade, label:"Suitable for grade {grade}", isCJK}`.
2. **vocabDiversity** — type-token ratio %, 1 decimal.
3. **sentenceLengths** — buckets ≤5 / 6–14 / 15–25 / >25 words with count + pct (CJK chars count as words).
4. **sentenceRhythm** — `[{sentence, wordCount}]` for every sentence.
5. **paragraphDensity** — per paragraph (split on `\n+`): `load = avgSentenceLen × weight`; latin weight = clamp(avgWordLen/4.7, .6–1.8), CJK weight = 0.55·(1+rareRate·2) (rescales ≈1.8 chars/word); load <7 simple / <13 medium / <20 complex / else dense.
6. **sentenceOpeners** — first token (leading quotes/punct stripped) → pronoun/article/conjunction/other; EN word-set match (spec lists; stray "the" kept in articles), ZH prefix match (我们/所以/但是…, 2-char entries first).
7. **passiveVoice** — be-verb (is/are/was/were/been/being/am/be) + participle (ends `-ed` len≥4, or 100+ irregular participles; `indeed/sacred/wicked…` false-positive blocklist); one skip word allowed (`was not finished`, `is often praised`); `{count, sentences}`.
8. **adverbs** — EN `-ly` (len≥4) minus noun/adj blocklist (family/holiday/monopoly/silly/lovely…); ZH `X地` (1–2 char stem + 地 + lookahead verb char) with 3 guard layers: noun-word blocklist (土地/目的/…), preposition-stem block (在/到/从…), 地-initial-noun block (地图/地方…). `{count, per1000, words}` (words = unique, first 60).
9. **wordFrequency** — content words top 10 (stopwords excluded per spec lists), count desc.
10. **wordEcho** — adjacent sentence pairs sharing ≥1 length≥2 non-stopword: latin content-word intersection + **maximal shared CJK substrings** (bigram-chain merge, all-stopword runs dropped) — makes the metric meaningful for Chinese (plain single chars would never qualify). `{count, pairs[≤12: {a, b, shared}]}`.
11. **repeatedPhrases** — 2–6-gram counts within sentences (chunked at commas/parens/dashes), count ≥3, sorted count↓ then length↓, subsumed shorter phrases dropped (token-contiguity check); CJK n-grams are char sequences by construction. Top 10.
12. **dialogueBalance** — quote-pair scanner over “” ‘’ 「」 『』 " ' (straight-quote toggle; apostrophe contraction guard `\w'\w`); dialoguePct = non-space chars inside quotes / total non-space chars; sentences containing quote chars listed.
13. **pointOfView** — per sentence the EARLIEST marker wins (spec: 按出现顺序优先): first (I/we/me/us/my/our/我/我们/咱/咱们), second (you/your/你/你们/您), third (he/she/it/they/him/her/them/his/her/their + 他/她/它/他们/她们/它们); name detection skipped per spec. `{first, second, third, total, examples{…}≤5}` (examples added so the UI can locate).
14. **punctuationHabits** — per-1000-words frequency groups ！! ？? ；; ：: —– 、 。 …(runs "…"×1-2 / "..."×3-6 = 1) ""(pair count) ()（）; count>0 groups sorted by per1000, top 8; `{char, label(EN key), per1000}`.
15. **summary** — `{sentences, words, paragraphs, avgSentenceLen}`.
