## Exported API surface (from `src/lib/local-mode.ts`)

- `installGuestApi(): void` — wraps `window.fetch`; any request whose pathname starts with `/api/` and is NOT under `/api/auth/` or `/api/import/` is served from localStorage and answered with a real `Response` (JSON, correct status). Idempotent (function marker `__zdocsGuestApi`); everything else passes through to the original fetch untouched.
- `uninstallGuestApi(): void` — restores the original fetch.
- `readGuestSnapshot(): GuestSnapshot` — `{ documents: [{ title, content, starred, trashed, folderId, stats(parsed object), editCount, tags: string[] (tag names) }], folders: [{ name, color }], sheets/decks/forms: [{ title, (description,) data, starred, trashed }] }` — full export for cloud sync on sign-in; empty structure when nothing exists.
- `clearGuestData(): void` — wipes the `zdocs-guest-db` key + resets memory.
- `hasGuestData(): boolean` — true when any content rows exist (memory or persisted).
- `guestDbStats(): { bytes: number; counts: Record<string, number> }` — TextEncoder byte size of the blob + per-table counts (documents/versions/comments/reactions/folders/tags/sheets/decks/forms/responses/activities).

## Guest-mode behavioral notes for the main agent (wiring guide)

- Call `installGuestApi()` in a client effect before any app data fetches when entering guest mode (and `uninstallGuestApi()` when leaving). No other client code changes needed — the app's plain `fetch("/api/...")` calls work as-is.
- Guest identity for comment/activity attribution comes from `readLocalUser()` (`zdocs-user` key); body authorId/authorName fields are ignored, mirroring the server's session-truth behavior.
- Persistence is one synchronous `JSON.stringify` per mutating request (autosave cadence ~1s is fine; multi-select batch loops are synchronous and trivially safe).
- Page reload hydrates from the blob; private-mode (setItem throws) silently degrades to in-memory.
- Dictionary entries needed: **NONE** — the two 403 messages are inline bilingual via `getCurrentLang()`, not dictionary keys.

## Shape quirks discovered while mirroring (handled exactly)

1. `POST /api/documents` returns the RAW Prisma row: `stats` is the raw string `""` (only GET/PATCH `[id]` parse it into an object).
2. `PATCH /api/comments/[id]` returns the raw comment row WITHOUT `replies`/`reactions` (only the GET comments route nests them).
3. `POST /api/sheets|slides|forms` hardcode `data:"{}"`/`"[]"` in the response while persisting the real body data.
4. Docs trash filter is `filter=trash`; sheets/slides/forms use `filter=trashed`.
5. `restore-version` does NOT bump editCount and logs NO activity; it snapshots the current state unconditionally.
6. `PATCH /api/documents/[id]/stats` bumps `updatedAt` (Prisma @updatedAt fires on every update).
7. Folder PATCH response has no `count`; folder POST includes `ownerId` + `count: 0`; tag responses never include `ownerId`.
8. Intentional guest deviations: no `sanitizeDocHtml` locally (server-only helper; content re-enters via server routes on sign-in sync which sanitize); `/api/export` includes ALL activities instead of filtering by actorId (single-user local DB).
