### API route details
- **System prompt** (Chinese, strict): output ONLY a JSON array `[{"quote","type","suggestion","message"}]`; quote must be a VERBATIM fragment (used for locate+replace); report each error once; ≤30 items; `[]` when clean; message always 简体中文; **message must not contain ASCII double quotes (use 「」)**; inner double quotes must be escaped.
- **Defensive parsing pipeline** (`parseIssueArray`): strip ```json fences → direct JSON.parse → parse first `[`…`]` span → **`repairUnescapedQuotes` last resort**. The repair pass was added after a REAL model response failed to parse: the model emitted unescaped inner quotes (`message":""Their"拼写错误…"`) — a genuine LLM JSON defect. The repairer walks the string, treats a quote inside a string as the closing quote only when the next non-space char is `, : } ]` or EOF, otherwise escapes it. After the fix the same live request returned a clean 200 with 4 issues.
- **Per-issue validation** (`toIssue` + loop): quote non-empty & ≤200 chars (else dropped); type normalized into spelling/grammar/punctuation/style (default grammar); suggestion/message trimmed & capped at 200; **quote must actually occur in the source text (case-insensitive containment)** so the client can always locate it; dedup by quote; hard cap 30 issues.
- Unparseable output → 502 `{error}` (+ server-side log of raw output, first 500 chars); ZAI/network failure → 502.

### Dialog details (client)
- **Auto-check on open** (and on language change while open): text extracted from `pageRef.current` with `extractText()` — a TreeWalker that replicates `findTextMatches`' exact block concatenation (`closest("p,h1,h2,h3,h4,li,td,th,blockquote,pre,div")`, `"\n"` between blocks) → **the text sent to the AI maps 1:1 onto the searchable text, so every returned quote is DOM-locatable**. Sliced to 12,000 chars (truncation hint shown). `fetch` POST with `credentials: "same-origin"`; sequence-guard ref kills superseded responses.
- **Issue cards**: colored type badge (拼写 red / 语法 amber / 标点 blue / 风格 violet) + bold clickable quote (line-clamp-2, `title` = full quote) + message + 原文→建议 comparison row (strikethrough → ArrowRight → primary-colored suggestion).
- **Locate**: click quote → `findTextMatches(pageRef.current, quote, true)` (case-insensitive fallback) → `scrollRangeIntoCanvasView` + `window.getSelection().addRange(range)` native highlight; not-found → friendly toast ("无法在文档中找到该文本 / 检查后文档可能已修改").
- **修正 (single fix)**: first match range → `range.deleteContents()` + `insertNode(textNode(suggestion))` → `el.normalize()` → `onFixed()` (editor autosave/stats) → card removed + toast `原文 → 建议`; disabled when no suggestion.
- **忽略**: removes the card.
- **全部修正 (fix-all)**: re-locates EVERY fixable issue first (duplicate quotes are assigned DISTINCT occurrences via an occurrence map), sorts by `match.start` DESCENDING, replaces back-to-front so earlier live ranges stay valid (same technique as the find/replace engine); per-fix 40 ms yield → live progress "正在修正第 {i}/{total} 处…"; one `onFixed()` at the end; toast "已修正 {n} 处问题" / "已修正 {n} 处（共 {total} 处）".

- **Errors**: 429 → "请求过于频繁，请稍后再试。"; 502/network → "AI 服务目前不可用。" + Retry button; Recheck always available in the footer.
